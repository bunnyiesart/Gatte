Tool security

Approving the configuration does not approve any tool. Each tool is reviewed and approved here, by its fingerprint; a sensitive tool also needs Clear. Each tool's actions are in its Actions menu.

A tool is served only after you approve it, and only at the exact version you reviewed. A sensitive tool (one that can act) needs clearing on top of approval before it is served.
