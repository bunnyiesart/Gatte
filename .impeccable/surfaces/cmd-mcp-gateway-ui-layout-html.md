# Surface: Gatte operator console (`mcp-gateway ui`)

Mode: Operate. A few operators take turns; routine tool approvals, rare incident actions (blocking an analyst, reading refusals, verifying the chain). Constraints: no JavaScript, CSP `default-src 'none'; style-src 'self'`, one embedded stylesheet, system faces only (light host), light and dark from prefers-color-scheme, blue and black shades only (brand commitment).

## Direction contract

THESIS: The console is a signal box. A lever cannot be pulled unless the route shown is the route locked; a tool cannot be approved unless the fingerprint shown is the one advertised. Refuses the KPI-card admin dashboard.

OWN-WORLD: Black enamel frame, iron panels, a navy illuminated diagram board, enamelled plates with tracked capital lettering, signal blue as the only colour that means you can act. Danger is inversion plus a hatched lever collar, never red. Tables are the train register book: ruled ledger lines, tabular numerals.

STORY: The operator sees what is locked, reads the definition as a model will, and pulls exactly one lever for exactly one fingerprint.

FIRST VIEWPORT: Nameplate and plate-tabs on the block shelf; below, the diagram board spanning the width with one track section per backend and each tool as a numbered lever mark (lit, dim, collared); one status line of counts under it; latest refusals as register lines.

FORM: Railway signal box lever frame and interlocking, position 3 of 7, seed key 1c240ecb.

Raises: approve names the irreversible fingerprint and sits after the diff (darkroom); signal blue is the only control colour (cape); one imperative per page on its caption plate (WPA); a fixed measure for definitions, one fingerprint line wide (zine); hidden code points as physical inverted marks (alphabet storm); one strict state grammar: pressed inverts, locked is collared, disabled is dimmed steel (one-bit).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
